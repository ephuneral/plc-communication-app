# Приложение коммуникации PLC и PostgeSQL
Это приложение позволяет считывать данные из PLC Siemens S7-1200 и записывать их в БД PostgreSQL
## Назначение
Приложение записывает данные из промышленного контроллера в базу данных. Отслеживаются биты, которые означают команду записи и чтения, а также реализован функционал live_bit для отслеживания контроллером связи с сервисом.

> [!CAUTION]
> Данная программа написана под конкретную задачу общения с системой АСУТП, что не позволяет запустить программу методом "Быстрый старт".
